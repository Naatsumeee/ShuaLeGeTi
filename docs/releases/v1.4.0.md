## 新增

- 设置页新增全局渲染比例调节（80%–125%），适配不同屏幕尺寸与分辨率。
- 大模型配置支持开启 OpenCode 请求头（含 User-Agent 与 x-opencode-session），兼容 OpenCode Go 端点。
- 题库维护「编辑题目 / 章节划分」支持按章节分块展示、任意两题间新建/删除分章标记、点击章标题改名及右侧快速滑块定位。
- 做题页新增题干右上角单题编辑与顶栏时间戳笔记，笔记按时间先后展示在解析下方并随题库文件导入/导出。
- 错题本重刷新增「重刷未掌握」标记与专属章节，本轮做对的题目在整轮完成后统一标为已掌握。

## 优化

- 震动反馈调整为 5 档（默认 3 档），采用前强后脆冲击曲线，并修复长时间未操作后首次震动丢失的问题。
- 主页底部导航栏改为真悬浮毛玻璃并叠加柔光模糊，长按支持拿起并连续跟手移动；减弱页面切换弹性动画。
- 压缩设置页滑块高度，修复深色模式下部分黑色文字显示不清的问题，题库详情页速刷说明同步显示设置的秒数。
- 精简导入、设置、生成、刷题准备等页面冗余文案，待确认导入卡片与预览页支持直接舍弃（含 0 题导入）。

## 修复

- 修复 LaTeX 下标偏上、超长公式挤压错乱及根号长顶线未正确渲染的问题，加入横向滚动条并支持组合数渲染。
- 修复百炼流式端点 HTTP 400（stream_options 缺少 include_usage）。
- 修复背题模式切题动画邻卡不显示解析、随机巩固与速刷等模式进度串联，以及错题本未选择题库时仍可选章节的问题。
